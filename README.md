# SAPIA Legal Navigator

Crie uma aplicação web responsiva para um sistema chamado SAPIA (Automação de Petição Inicial para Advocacia Previdenciária).

Estilo e Identidade Visual: Estilo profissional, moderno e clean voltado para o setor jurídico/tecnológico.

Paleta de cores: Fundo cinza bem claro (#F8FAFC), elementos de navegação e texto em azul-marinho profundo/grafite (#0F172A), e botões primários em azul tecnológico com cantos levemente arredondados (rounded-lg) e sombras suaves.

Tipografia limpa, moderna e legível.

1. Cabeçalho Fixo (Navbar):

À esquerda: Logo SAPIA bem destacada.

Ao centro: Links de navegação para 'Enviar arquivos' e 'Histórico de Arquivos'.

À direita: Link 'Cadastre-se' e botão em destaque 'Entrar'.

2. Tela de Cadastro (/cadastro):

Card centralizado com o título Cadastre-se.

Campos com ícones discretos e labels claras: 'Nome completo', 'E-mail', 'Senha' e 'Confirmar senha'.

Botão principal: 'Finalizar'.

Validação visual nos campos: nome entre 3 e 100 caracteres, e-mail válido, senhas coincidentes e senha forte com no mínimo 8 caracteres (com letras maiúsculas, minúsculas, números e caractere especial). Exibir mensagens de erro amigáveis caso os requisitos não sejam cumpridos.

3. Tela de Login (/login):

Card centralizado com o título Login.

Campos: 'E-mail' e 'Senha'.

Link para 'Esqueci a senha'.

Botão principal: 'Entrar'.

Garanta que a navegação entre a tela de cadastro e a de login esteja funcionando ao clicar nos botões do cabeçalho e nos links.

Anexei os protótipos das telas solicitadas, você deve seguir o modelo apresentado.
